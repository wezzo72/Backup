  • Would the same inventory appear if the author’s name were concealed? The tree listing would. No pattern of misconduct is declared from a file count.

This batch’s own method does not confirm that, because almost every file was only listed. The register URL does not contain the register. Twenty PDF names resolve to the word Gone.
