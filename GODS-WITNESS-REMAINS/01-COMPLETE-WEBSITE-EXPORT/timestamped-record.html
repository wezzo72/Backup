Timestamped record of evidence and website preservation

This archive provides cryptographic evidence that the following materials existed in this form at the recorded date and time. It does not itself establish the truth of every claim. Truth has to be assessed from the documents, from independent checking, and from whatever lawful process a reader trusts. A hash does not make the live website unerasable. The site can still be edited. What cannot be quietly altered is this snapshot, if the proof later confirms.

This snapshot

  • Taken: 12 November 2026, 08:16:55 UTC. That is 7:16pm Australian Eastern Daylight Time.
  • What was saved: the source text of 475 pages, and the HTML the local site returned for each of those pages. 950 files. 195,860,237 bytes. This proof page was written after that snapshot, so it is not inside the root.
  • SHA-256 Merkle root: b85d4f0580b7ece8866f83d9eb6c1b39f7adda35155194ecdc4151315a452acd
  • How the root was made: each file’s SHA-256 is a leaf. The files are sorted by path. If a level has an odd count, the last digest is repeated. A parent is the SHA-256 of the two child digests joined together.
  • Bitcoin: the root file was submitted to OpenTimestamps calendars at about 08:17 UTC. The calendars say pending confirmation. There is no transaction id and no block height. Pending is not a confirmed stamp.
  • Proof file: MERKLE_ROOT.txt.ots
  • The root itself: MERKLE_ROOT.txt
  • Every file hash: MANIFEST.jsonl
  • Download of the source pages, the manifest, and the proof: 2026-11-12-snapshot-proofs.zip. The rendered HTML is on this copy of the site, in the same folder, and is not inside that zip.

At 07:21 UTC the same day, a different set of 1,023 files was hashed. Its root is 470dabc3d6217f93f7f893f184ebf718c3021e95f4042949f18c17d70db8dbb4. That proof is also waiting on Bitcoin. It was not replaced by the root above. The two roots are two different piles of files.

How a third party checks it

  1. Install OpenTimestamps: ots.
  2. Download MERKLE_ROOT.txt and MERKLE_ROOT.txt.ots into the same folder.
  3. Run ots verify MERKLE_ROOT.txt.ots.
  4. Until Bitcoin confirms the calendar, the reply will say pending. After it confirms, the reply will name a Bitcoin block. That block time is the proof that the root existed at or before that time.
  5. To check a single page, hash the file with SHA-256 and find that hash in the manifest. The manifest’s own hash is one of the leaves, so a confirmed root covers the list.

A confirmed stamp proves existence and integrity of these bytes. It does not prove that an agency wrote a letter, that an allegation is true, or that a later edit of the live site did not happen.

What was not done

  • No WARC file was made.
  • The GitHub PDF repository was not inside this snapshot. A separate copy of written files from that repository is still running, and it is not this root.
  • Nothing was uploaded to Google Drive in this step. Nothing was sent to the Internet Archive. No external drive was attached here.
  • Nothing was redacted inside the snapshot. The pages were saved as published. A reader who shares the zip further should still leave out a street address, a medical image, and a method of self-harm if they make a new public post.
  • IPFS and Arweave identifiers were not created.

If you keep another copy

Google Drive: put the zip in a folder named “Witness Remains — snapshot 12 November 2026”, and do not let that folder be the only copy. Internet Archive: after this site is on its public address, a person can ask the Wayback Machine to save this page. That save is a third copy only if it succeeds. An offline copy means the zip on two drives, one of them not in the same house, with a password you choose. This page cannot do that for you.

Versions

If a page is later corrected, the old wording stays in this snapshot. The correction is written on the live page and dated. This root is not rewritten to match the correction. A new snapshot gets a new root.

Why the record is being kept

I am preserving this record so that the evidence cannot quietly disappear. I invite independent examination, lawful investigation, and accountable institutions to assess the facts. My aim is not personal glory, but truth, protection for those harmed, and accountability under law.

The testimony on the other pages is the author’s, and it includes his faith. This page does not ask a reader to treat faith as a finding, and it does not ask a reader to treat a hash as a verdict.
