The Witness Remains
Master government evidence repository
1990–2026

This page is the result of the search that could actually be made. It is not a claim that every account was opened. A filename names the file. The testimony does not wait for approval of the name. A file being in the repository does not prove every allegation made about it.

What was searched

  • GitHub, public repository wezzo72/Barrandodger. The file tree was retrieved in full. It was not truncated. It contains 7,441 objects, of which 4,128 are PDFs.
  • This website. The files already linked from these pages were compared with that tree. 1,466 catalogue paths matched a repository PDF path. 3,171 repository PDFs did not match a path already listed on this site. Some of those may be the same document stored under another name. That was not decided by reading them.
  • Google Drive, the connected account. The first page of the root was listed. It was not the whole Drive. Nested folders were not opened. Personal files in that root were not copied onto this website.

What was not searched

  • Apple, iCloud, Apple Notes and the Files app. There is no connection to those accounts. An export, or the files themselves, would have to be provided.
  • ChatGPT. Conversation exports and uploaded files were not available. They would have to be exported and supplied.
  • Dropbox. The live Dropbox account was not opened. A folder already inside the GitHub repository is named dropbox-iphone-pdfs. That is a copy in GitHub. It is not a search of Dropbox.

What was not done

The PDFs were not downloaded. Their text was not extracted. OCR was not run. Page counts were not taken. Recipients, letterhead and signatures were not read. SHA-256 hashes were not calculated. No blockchain timestamp was created in this pass. The Git identifier in the register is a Git blob identifier. It is not a SHA-256 of the file.

No duplicate was deleted. Where the same Git blob appears at more than one path, the register keeps every path. There are 280 such groups, amounting to 403 extra paths. They remain in the repository.

The financial assessment was not recalculated. A loss figure cannot be made from a filename.

The register

Download the register (CSV). It has one row for each of the 4,128 PDFs. Each row has an identifier, the filename, the year if the filename states one, a shelf taken from the filename, the repository path, a link to the file on GitHub, the Git blob identifier, and whether that path was already linked on this website. The columns for recipient, page count, SHA-256 and what the document establishes say that those things were not read.

3,374 PDFs have no year from 1990 to 2026 in the filename. Of those that do, the earliest is 1996. No PDF filename in this tree carries 1990, 1991, 1992, 1993, 1994, 1995, 1997, 1998, 1999, 2001, 2002, 2003, 2005, 2009, 2011, 2012 or 2014. Those gaps are not filled.

A referenced record that was not found

The dated chronology names NSW Trustee and Guardian matter 658238. That number does not appear in any path in this repository tree. The file is recorded as missing from this search. It is not invented.

The string 1326583 appears in eight paths, including a file whose name begins 2021-05-25-Comcare-Claim-1326583. The participant number 430938559 appears in three paths. Those are paths. They are not a reading of the documents.
